# Сквозная аналитика и DWH (Marketing & Sales)

Проект корпоративного хранилища данных (DWH) в Google BigQuery. Объединяет расходы из рекламных кабинетов, заявки с сайта и воронку продаж из amoCRM для расчета итоговой эффективности бизнеса (ROMI, CAC, CPL, конверсии).

## Стек технологий
* **Хранилище:** Google BigQuery
* **Трансформации данных:** SQL (построение витрин, очистка, джойны)
* **Источники:** amoCRM, Google Ads, Facebook Ads, Webhooks
* **BI:** Визуализация метрик и сборка дашбордов

## Структура проекта
Проект разделен на независимые бизнес-домены. Внутри каждого домена находятся JSON-схемы контрактов (`raw_data`), SQL-логика (`sql`) и примеры отчетов (`dashboard_sheets`):

* `costs_analytics/` — обработка маркетинговых расходов.
* `sales_analytics/` — аналитика сделок, этапов воронки и комиссий из amoCRM.
* `applications_analytics/` & `regs_analytics/` — учет входящих заявок и регистраций.
* `checkins_analytics/` — отслеживание фактической доходимости (чекинов).
* **`combined_data_analytics/`** — итоговый слой сквозной аналитики, связывающий затраты с реальными продажами по UTM-меткам.
